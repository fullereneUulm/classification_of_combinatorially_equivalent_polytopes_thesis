All folders are named according to the choice of parameters alpha and beta in the following character definition:

tr(exp(alpha*A + beta * D))

Folder name: "alpha[alpha value]_beta[beta value]".

Further, the filenames containing the values of characters are named in the following way:

File name: "character_T_[n].txt" or "character_T6_[n].txt",
 
Where, "T" or "T6" specify whether graph T_n or T_n^6 is represented by adjacency matrix A and degree matrix D, and n is the number of vertices in the direct fullerene (number of atoms) and the index of C_n.
